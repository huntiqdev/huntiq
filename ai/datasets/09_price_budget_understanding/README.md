# HUNTIQ Dataset Module 09 — Price and Budget Understanding

## 1. Module Overview
- **Module ID:** `09_price_budget_understanding`
- **Domain:** `numeric_currency_nlu`
- **Primary Languages:** English (`en`), Amharic (`am`), Afaan Oromoo (`or`), Tigrinya (`ti`)
- **Format:** JSON Lines (`.jsonl`)
- **Schema:** [`schema.json`](./schema.json)
- **Manifest:** [`manifest.json`](./manifest.json)
- **Sources & Provenance:** [`sources.json`](./sources.json)
- **Data Dictionary:** [`data_dictionary.md`](./data_dictionary.md)

## 2. Purpose & Scope
Interpret Ethiopian Birr (ETB) figures, suffixes (k, M), ranges, periodic rental rates (monthly, daily), and budget constraints.

All examples in this dataset module relate directly to the HUNTIQ marketplace ecosystem in Ethiopia.
